発行処理の詳細

01 / ISSUE

GASがキーを発行

同期トークンを検証してからランダムなキーを生成。同じ名前のキーは置き換えます。

02 / STORE

GASにはハッシュを保存

照合用ハッシュだけをスクリプトプロパティに記録。キー本体は登録後に保持しません。

03 / EXPORT

JSONを端末へ保存

JSONファイルの各フィールドの意味

remote-settings-key.json はこのような形式のテキストファイルです。各フィールドの意味は以下の通りです。

{ "gasUrl": "https://script.google.com/macros/s/…/exec", "key": "rsk_（64桁の英数字）", "label": "山田先生" }
"gasUrl"
WebアプリのURL
GASのデプロイURL。https://script.google.com/macros/s/…/exec という形式。教室PCのスプレッドシートと通信するための宛先です。管理者が変えない限り変わりません。
"key"
操作キー（パスワード）
rsk_ で始まる68文字のランダムな文字列。このページまたはスプレッドシートのメニューから発行され、GASにはハッシュだけが保存されます。この値だけが「誰が操作しているか」を証明するものなので、他人に渡さないでください。紛失・漏洩した場合は管理者に連絡して失効させてください。
"label"
名前（ラベル）
依頼の記録に表示されるキーの名前（例：山田先生）。キーを発行したときに入力した名前と同じです。接続後の画面でも表示されます。

セキュリティについて

キーはパスワードと同じです

操作キーを持っている人は、教室PCの設定変更を依頼できます。メールやチャットには貼らず、USBの中だけで管理してください。

キーは画面を閉じると消えます

remote-settings.html を使うとき、入力した操作キーはパソコンに保存されません。ブラウザのタブを閉じると自動的に消えます。

USBを紛失したらすぐ連絡を

USBをなくした場合は管理者にすぐ連絡して、スプレッドシートのメニューから「キーを失効」してもらってください。失効すると、そのキーはすぐ使えなくなります。
